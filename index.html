Project Abstract

Predicting video popularity and audience engagement is a central challenge for content creators and marketers. This application models engagement rates using state-of-the-art deep learning architectures:

  • Text Feature Extractor: Bidirectional LSTM with Attention layer processing title, description, and tags.
  • Visual Feature Extractor: ResNet18 convolutional neural network encoding thumbnail aesthetics.
  • Tabular Metadata MLP: Batch-normalized Multi-Layer Perceptron processing categories and view statistics.
  • Graph Neural Network (GNN): Graph Convolutional Networks (GCN) that propagate features across videos based on channel and category similarities.
